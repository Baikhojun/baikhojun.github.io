# 설문 응답 수집 주소

- 작성일: 2026-11-17
- 담당: Codex
- 사용자 요청: 모바일 설문 초안 생성과 응답 한 건의 자동 저장을 구현하고 배포한다. DB를 사용하지 않는다.

## 주소

- `/survey/`: 응답자 진입 주소이다. 전달받은 초대 링크로 접속한다.
- `/survey/admin/`: 운영자 진입 주소이다. 운영자 전용 링크로 접속한다.
- `/survay/`: 사용자 요청 표기를 고려한 별칭이다. `/survey/`로 이동한다.

GitHub Pages는 진입 페이지만 제공한다. 설문 화면과 제출 API는 Sites의 별도 서비스에서 제공하므로 Lightsail Polo 서버의 장애와 독립적으로 동작한다. URL fragment의 키는 이동 과정에서 보존하고 실제 앱이 로드되면 주소창에서 제거한다. 키를 서버의 URL 쿼리로 전달하거나 공개 소스에 포함하지 않는다.

## 수집 방식

다섯 문항의 선택과 검토한 답변을 비공개 파일 저장소에 JSON 한 건으로 저장한다. 조건부 쓰기로 동시 제출을 제한하고 같은 응답의 재시도는 중복 저장하지 않는다. 응답자 키로 기존 답변을 읽을 수 없으며, 운영자 화면만 응답 조회와 HTML·JSON 다운로드를 제공한다. 운영자는 화면의 링크 복사 버튼으로 응답자 링크와 본인 운영자 링크를 각각 보관할 수 있다.

원본 HTML의 부정 응답이 다른 의견으로 강제 연결되는 문제를 객관식과 의견 없음 항목으로 개선하였다. 수정 내용 보존, 임시 저장 복원, 복사 실패 알림, 제출 동의와 모바일 확대 기능을 제공한다. 외부 분석 도구와 DB를 사용하지 않는다.
