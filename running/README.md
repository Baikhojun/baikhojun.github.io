# FIRST 3K WOMEN

여성 초보자의 일상 3km 러닝화 구매 비교 도구입니다.

- 배포: https://unfade.is-a.dev/running/
- 모바일 바로가기: https://unfade.is-a.dev/running/m/
- 데이터 확인일: 2026-10-20 (화면과 데이터 원장에 상세 확인 시각 표시)
- 여성 판매 품번 18개 / 기본 초보 데일리 필터 17개 / 사진 141장
- 같은 세대 RunRepeat 17개 / Running Shoes Guru 13개 / 두 사이트 일치 쌍 13개

## 파일

`index.html`이 PC와 모바일에서 같은 데이터를 표시합니다. `m/index.html`은 모바일 사용자를 구매 비교 구역으로 안내하는 바로가기입니다. `ui.css`, `mobile.css`, `web.css` 순서로 스타일을 적용합니다. `app.js`는 점수·표·차트·사진 UI, `mobile.js`는 하단 도구와 필터/정렬 시트·브라우저 내 설정 저장을 처리합니다.

`data.js`에 가격, 점수 원자료, 모든 실험 지표, 계산식, 검증 기록과 원문 URL이 들어 있습니다. 화면의 JSON/CSV 다운로드로 확인할 수 있습니다. 이 배포에서는 기존 검증 데이터의 가격·점수를 바꾸지 않았습니다. 자동 가격 수집이나 실시간 업데이트는 없습니다.

`assets/photos/`는 검증된 실제 사진 141장이고 `assets/thumbs/`는 같은 사진의 목록용 축소본입니다. 원래 프레이밍·색·투명도를 유지했으며 생성 이미지나 제품을 변형한 이미지는 없습니다. 사진별 원권리자와 원문은 데이터 및 상세 화면에서 확인합니다. 목록은 썸네일을 사용하고 상세 큰 이미지에서 원본 배포용 사진을 불러옵니다.

## 유지보수

빌드 과정 없이 정적 파일을 수정하고 브라우저에서 검증한 후 main에 반영합니다. 스크립트와 데이터가 함께 바뀌면 index.html의 `?v=4` 캐시 버전을 올립니다. 점수의 결측값은 null로 유지하고 다른 세대의 리뷰로 채우지 않습니다. 두 사이트 총점 평균은 `(RunRepeat + Guru × 10) / 2`이며 두 총점이 모두 있는 경우에만 표시합니다. 남성 US9 실험 수치는 여성 230 실측으로 바꾸지 않습니다.

로그인, 서버 저장, 외부 분석 추적 스크립트는 없습니다. 필터와 비교 선택만 방문자 브라우저의 localStorage에 저장합니다. 기존 사이트의 검색 비노출 정책을 따라 noindex,nofollow를 유지합니다.
