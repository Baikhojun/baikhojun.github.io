# 브리타 정수기 비교 (신혼부부 가이드)

한국 수돗물 기준으로 브리타 물병형 정수기 본체 7종·필터 2종·판매 구성 33개를 비교하는 정적 페이지입니다.

- 배포: https://unfade.is-a.dev/brita/
- 모바일: https://unfade.is-a.dev/brita/m/ (휴대폰은 PC 주소에서 자동 이동, `?pc`로 PC판 고정)
- 가격 기준일: 2026-10-26 (브리타 공식몰 첨부 화면 관측값, 실시간 가격 아님)

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | PC판. 왼쪽 목차와 긴 스크롤 |
| `m/index.html` | 모바일판. 하단 탭 5개(결론·본체·필터·비용·박사 검토·구매) |
| `data.js` | 본체·필터 사양, 판매 구성 33개, 공식 사양 출처, 네이버 공식 스토어 링크 |
| `review.js` | 수질 박사 관점 독립 검토(42개 항목·상황별 권고·최종 의견), 한국·유럽 경도 |
| `app.js` | 두 화면 공용 계산·그래프·구역 렌더링 |
| `brita.css` | 공용 스타일(라이트·다크) |
| `assets/` | 브리타 공식 사이트 제품 이미지를 WebP로 축소한 14장 |

## 유지보수

빌드 과정이 없습니다. 가격이 바뀌면 `data.js`의 `skus`를 고치고 `asOf`를 갱신한 뒤, 세 HTML의 `?v=` 캐시 번호를 올립니다. 미확정 수량은 `null`로 두고 0으로 바꾸지 않습니다. 계산(개당 단가, 묶음 한계비용, 최저 조합, 연간 비용)은 `app.js`가 데이터에서 매번 다시 계산합니다.

로그인·서버 저장·추적 스크립트가 없습니다. 계산기 설정과 가격 기준만 방문자 브라우저의 localStorage에 저장합니다. 사이트 정책에 따라 noindex,nofollow를 유지합니다. 광고·제휴 링크는 쓰지 않습니다.
