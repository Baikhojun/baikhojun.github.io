# cuckoo — 쿠쿠 밥솥 모델코드 해독 프로젝트

개인 프로젝트 (YERP 업무 아님). 쿠쿠 공식몰 전 모델을 크롤링해 모델명 파싱 규칙을 역공학하고,
"특가가 진짜 특가인지" 판정하는 오프라인 HTML 도구를 만든다.

- **GitHub**: https://github.com/Baikhojun/cuckoo-decoder (private, main 브랜치). gh CLI 인증됨(Baikhojun, keyring).
  작업 후 커밋·푸시: `git add -A && git commit && git push` (이 폴더가 repo 루트)

## 핵심 파일

- `cuckoo-decoder.html` — 최종 도구 PC판 (브라우저로 열면 동작)
- `cuckoo-decoder-mobile.html` — 모바일판 (폰 브라우저로 열면 동작, 오프라인)
- `cuckoo-master.md` — 마스터 문서 (파싱 규칙·가격 분석·기준선 방법론·변경 이력)
- **재생성: `python build_all.py`** (build_v3 → build_weights → build_v3 → HTML 2종. 감가 곡선이 가중치 산출물이라 build_v3 2회 필요)
- 크롤 갱신 시: `python update_source.py`(소스 가격·재고·신규 갱신) → `python crawl_detail.py`(스냅샷 기록+신규 상세) → `python build_v3.py` → `python crawl_danawa_spec.py`(신규 스템 스펙) → `python build_all.py`
- 웹 배포: 쿠쿠 = `baikhojun.github.io` repo `cukoo/index.html`·`cukoo/m/index.html` 에 HTML 2종 복사 후 푸시 (https://unfade.is-a.dev/cukoo/). TV = `TV/deploy_tv.py` 출력
- `snapshots/` — 가격 스냅샷 누적 (crawl_detail 실행마다 자동 추가, 지우지 말 것)

## 결정사항

- NL/FF = 병행 변형 코드 (세대 아님, 등록월 거의 동시). 같은 스펙이면 싼 쪽 구매.
- 표시창 앞 `T` = IoT(WiFi) 모듈.
- 올스테인리스(내솥 5등급)는 코팅의 상위호환으로 취급하지 않음 (지배 규칙에서 제외).
- 연식 감가: 2/4/6/8년 경과 시 1.0/0.97/0.92/0.85/0.70, 구형 명명(H앞·AH·BH) 추가 ×0.85.
- 대용량밥솥 카테고리(categoryCd=57)는 계속 제외.
