## 1. 확정된 파싱 규칙 (206개 전수 검증)

### 1-1. 구조


### 1-2. 디자인 + 가열방식 — **2글자 묶음** `★★★`

**신형 명명 (2018년 이후): `[글자] + H` = IH**

**구형 명명 (~2018): `H + [글자]`**
`HQ` `HU` `HV` `HW` `HM` — 총 8개 모델. **파서는 `H`로 시작하면 구형으로 분기**해야 합니다.

**열판(비IH) 그룹** — `H`가 없음

| 코드 | 라인 | 트윈프레셔 | 관측 수 |
|---|---|---|---|
| `ST` | **더 라이트** | ✅ | 17 |
| `UT` | **사일런스 어반** | ✅ | 4 |
| `TT` | 트윈프레셔 미니(3인용) | ✅ | 2 |
| `P` `PK` | P형 열판압력 | ✖ | 8 |

> 💡 **`UT`(사일런스 어반)는 함정입니다.** 이름에 "사일런스"가 붙고 트윈프레셔도 있지만 **`H`가 없어 열판식**입니다. 공식 "사일런스 밥솥" 카테고리(24개)에도 **포함되지 않습니다.** 사일런스 IH 라인(`NH`/`OH`/`PH`/`QH`)과 완전히 다른 물건인데 이름이 비슷합니다.

### 1-3. 특수기능 `★★★`

| 코드 | 의미 | 판별 |
|---|---|---|
| `T` | 트윈프레셔 | 디자인 코드 바로 뒤 |
| `L` | **저당** | 뒤에 내솥 `R`이 따라와 실질적으로 **`LR` 덩어리**로 나타남 |
| 없음 | 표준 | |

**저당 판별 규칙 (13/13 검증)**: 모델명에 **`LR`이 있으면 저당**.
`LHLR`, `KHLR`, `OHNLLR`, `PHNLLR`, `NHNLLR`, `OHFFLR`, `PHFFLR`, `NHFFLR`, `QHLRNL`

> ⚠️ `LHR`(예: `CRP-LHR0610FGW`)은 **`LH` + `R`** 이므로 저당이 **아닙니다**. `LHLR`과 한 글자 차이입니다. 파서는 반드시 디자인 2글자를 먼저 떼고 판단해야 합니다.

## 5. HTML 도구용 파싱 알고리즘 (검증 완료)

```
1. 접두사: CRP-(압력) / CR-(비압력)
2. 첫 숫자 위치로 [문자블록][숫자블록][꼬리] 분리
3. 문자블록:
   a. 3글자가 DESIGN_IH에 있으면 (BDH, BCH) → 디자인, IH
   b. 2글자가 DESIGN_IH에 있으면 (DH, LH, OH…) → 디자인, IH
   c. 'H'로 시작하고 2글자가 DESIGN_IH_OLD에 있으면 → 디자인, IH, [구형 플래그]
   d. 그 외 → GROUP_PLATE에서 긴 것부터 매칭 → 디자인, 열판
4. 남은 문자에서 'NL' 또는 'FF' 제거 → 변형 코드
5. 남은 문자 선두:
   'T' → 트윈프레셔 / 'L' → 저당(+트윈프레셔)
6. 내솥: [AS, AR, XB, R, S, P, B, F] 순서로 긴 것부터 매칭
7. 숫자: 앞 2자리 = 용량, 나머지 = 유통코드(무시)
8. 꼬리: (표시창1글자 + 색상)이 둘 다 사전에 있으면 그렇게, 
         아니면 전체를 색상으로, 끝의 M은 서픽스로 분리
9. 미해독 문자가 남으면 confidence를 낮추고 사용자에게 경고
```

**매칭 순서가 중요한 이유**
- 내솥: `AS`를 `S`보다 먼저 매칭하지 않으면 30만원 올스텐을 26만원 코팅으로 오판정
- 디자인: 2글자를 먼저 떼지 않으면 `LHR`(마스터셰프)을 `LR`(저당)로 오판정
- 구형: `H` 시작 분기가 없으면 `HVB06BS`가 파싱 실패

**테스트 세트** — `build.py` 실행 시 206개 전량 자동 검증됩니다.

## 7.10. 연식 감가 곡선 — 데이터 추정 (v3.4) `★★★`

기존의 계단식 **가정**(2/4/6/8년: 1.0/0.97/0.92/0.85/0.70)을 데이터 추정으로 교체.

**방법** (`build_weights.py`)
1. 로그가격 헤도닉에서 연속 연차 대신 **연령구간 더미**(0-2y 기준, 2-4/4-6/6-8/8y+) → exp(계수) = 구간 잔존율
2. 부트스트랩 300회 95% CI
3. **PAV(pooled adjacent violators) 단조화** — 나이 들수록 잔존율 비증가 제약
4. **결합 규칙**: 표본이 얇아 CI가 넓은 노후 구간에서 경험값이 기존 가정보다 관대하면 보수 가정 유지
   → `final = 단조화(min(경험 단조값, 기존 가정))`
5. 대조 모델: 지수 감가(연속 age 로그 계수) — 연간 잔존율 97.6%

**2026-08 결과**: **1.0 / 0.902 / 0.902 / 0.85 / 0.70** · 구형 명명 라인 추가 잔존율 **0.743**(실측, 기존 가정 0.85보다 엄격)

1. **가격 판정** — 모델명 + 제시가를 넣으면 `역대급 / 진짜 특가 / 적정 / 보류 / 절대 사지 마세요` 5단계 판정. 특가 낚시를 그 자리에서 걸러냅니다
2. **절대가격 기준선 사다리** — 모델별 4개 컷을 시각화. 공식몰가가 상한을 넘는 모델은 별도 경고
3. **전체 리스트 + 정렬** — 212개 전체를 모델/라인/용량/스펙/내솥/**출시(등록월)**/정가/몰가/할인율/특가컷/절대상한/리뷰수 열로 표시, **모든 열 클릭 정렬(오름/내림)**, 카테고리·용량 필터, 모델명 검색
4. **미등록 신모델 판정** — DB에 없는 모델도 코드 해독 후 동급 스펙 기준으로 기준선을 추정해 가격 판정 (추정치 표기)

**유지 기능**: 코드 해부 스트립 · 판정 패널(+ 사일런스/IoT 칩 추가) · 색상 형제 비교(출시월 표시) · 동급 대안 · 상황별 경고(연식/구형/UT 함정/IoT 의존성 추가)

**검증 상태**: JS 디코더가 Python 레퍼런스 구현과 **212개 전량 동일한 결과**를 냅니다 (가열·트윈·저당·내솥·용량·변형·IoT·사일런스·스템 9개 필드). 소문자 입력, 하이픈 누락도 처리. 인식할 수 없는 디자인 코드는 추측하지 않고 거절합니다.

**도구가 답할 수 없는 것**: 최대기압, 에너지효율등급, 소비전력. 모델명 코드에 없는 정보라 상세페이지 확인이 필요합니다. 도구도 그렇게 안내합니다.
