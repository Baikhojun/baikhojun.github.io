# UNFADE. — 신혼집 가전 사기: 쿠쿠 밥솥 모델코드 해독기

쿠쿠 공식몰 **전 모델(213개, 2026-09-16 기준)** 의 모델명 규칙을 역공학해서, 홈쇼핑·오픈마켓의 "특가"가
**진짜 특가인지**를 데이터로 판정하는 오프라인 웹 도구. 서버·DB 없이 HTML 파일 하나로 동작한다.

## 사용법

| 파일 | 용도 |
|---|---|
| **`cuckoo-decoder.html`** | PC판 — 브라우저로 열면 끝 |
| **`cuckoo-decoder-mobile.html`** | 모바일판 — 폰에 파일을 옮겨 브라우저로 열기 (하단 6탭 앱형 UI) |

둘 다 오프라인 동작(데이터 내장), 다크모드 지원(우상단 🌙 토글 + 시스템 설정 자동 감지).

## 기능

- **가격 판정** — 모델명 + 제시가 입력 → 역대급/특가/적정/보류/금지 5단계. 모델별 절대가격 기준선(연식 감가 반영) 기반
- **상황별 추천** — 8개 상황(1인/신혼/가족/대가족/혈당/소음/요리·이유식/예산) × 3단계, 현시점 사유 자동 생성
- **1:1 비교** — 스펙 diff + 가격차를 회귀 가중치로 해부("정당한 차이 vs 거품")
- **조건 빌더** — 조건 조합 → 실존 모델 검색 + 회귀 예상가
- **코드 사전** — 모델명 91개 코드 전부 상세 설명 + DB 실측 + 검색
- **항목별 가중치** — 헤도닉 회귀 v2 (부트스트랩 신뢰구간 → "믿을 만함/불확실")
- **지배 분석** — 판매중 203개 중 148개 "대안있음" → 알짜 선택지 55개
- **실측 스펙** — 최대기압·소비전력·에너지등급 (쿠쿠몰+다나와 크롤, 소비전력 207/213)
- **가격 관측 이력** — 크롤 스냅샷 파일 누적 (`snapshots/`)
- **후속작 리스크** — 라인별 신모델 웨이브 주기로 다음 리비전 시점 추정

## 재생성

```bash
python build_all.py            # 전체 재생성 (build_v3 → build_weights → build_v3 → HTML 2종)
```

크롤 데이터까지 갱신할 때:

```bash
python crawl_detail.py         # 쿠쿠몰 리스트+상세 (가격 스냅샷 자동 누적)
python crawl_danawa_spec.py    # 다나와 스펙 보완 (기압·소비전력·등급)
python build_all.py
```

## 방법론 요약

절대가격 기준선 = min(자기 몰가, 색상형제 최저, 동스펙 최저×1.05, 상위스펙 지배자×0.97) × 연식 잔존율.
연식 잔존율은 연령구간 헤도닉(로그) + 부트스트랩 + PAV 단조화 + 보수가정 결합으로 추정
(2년 이내 100% / 2~6년 90% / 6~8년 85% / 8년+ 70%, 구형 라인 ×74%). 상세: `cuckoo-master.md` §7.

> 개인 프로젝트. 데이터: 쿠쿠 공식몰 + 다나와 (2026-08 수집). 구매 손실을 보장하지 않음.
